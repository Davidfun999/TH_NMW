# images/

Thư mục này dùng để lưu ảnh cho EXIFSHARE.

## Cách dùng

Thêm ảnh vào thư mục này rồi cập nhật CSS trong `css/style.css`.

Ví dụ thay thế background CSS art bằng ảnh thật:

```css
.post-image--mountain {
  background: url('../images/4587570.jpg') center/cover no-repeat;
}

.post-image--forest {
  background: url('../images/forest.jpg') center/cover no-repeat;
}
```

## Định dạng được hỗ trợ
- `.jpg` / `.jpeg`
- `.png`
- `.webp` (khuyến nghị — nhỏ hơn, chất lượng tốt)

## Gợi ý kích thước
- Ảnh bài đăng: tỷ lệ 3:4, tối thiểu 800×1067px
- Avatar: 100×100px, hình tròn
